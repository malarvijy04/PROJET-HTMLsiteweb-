# Logifac

Site web d'une résidence étudiante, réalisé pour le projet de programmation Web TI504N (EFREI, 2026-2027).

## Pages du site

- **Accueil** (`index.html`) : présentation de la résidence, carrousel de photos et services
- **Logements** (`logement.html`) : les 3 types de logement et un tableau comparatif
- **Réservation** (`reservation.html`) : formulaire avec calcul automatique du prix
- **À propos** (`àpropos.html`) : l'équipe et le projet
- **Contact** (`contact.html`) : informations pratiques et formulaire de contact

## Technologies

HTML5, CSS3 et JavaScript, sans framework ni bibliothèque.
